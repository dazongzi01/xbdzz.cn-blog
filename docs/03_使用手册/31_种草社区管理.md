# 种草社区管理

## 社区分类

功能说明：为社区文章提供分类功能，是发布种草的必填属性之一，支持用户根据分类进行种草内容检索。

**位置**：平台后台 → 营销 → 种草社区 → 社区分类

![image](images/12be446c6e73e5df372b81d6c79e2b1a.png)

### 1. 添加社区分类

**第一步**：在社区分类列表中，点击【添加社区分类】按钮，打开添加社区分类弹窗；

![image](images/545192020a527e731a017731c85c65fd.png)

**第二步**：在添加社区分类弹窗中，填写分类信息，点击【提交】按钮，添加社区分类完成。

![image](images/7ffdbb4a59811e0021ab819a60eda49a.png)

### 2. 社区分类说明

- 社区分类只有1级
- 开启/隐藏：隐藏后，移动端新增社区种草与发现列表分类栏不展示对应的分类
- 删除社区分类时，必须保证分类下没有关联文章

## 社区内容

### 1. 功能介绍

社区内容指用户在移动端商城种草模块发布的内容，主要包括图文和视频两种内容形式，平台后台进行审核、下架、删除、排序、推荐等操作。

**位置**：平台后台 > 社区 > 社区内容

![image](images/fd7e37889fdff06ea9265b23ad8714cc.png)

### 2. 内容审核

功能说明：社区内容分为待审核和全部列表，待审核对应需要审核的内容进行审核，审核通过之后用户端成员才支持查看。

**第一步**：点击【审核】按钮，打开社区内容审核侧滑；

![image](images/bfbd0fb28ab3f362a5c6802fe7a61c6f.png)

**第二步**：在社区内容审核侧滑中，点击【审核通过/审核拒绝】进行审核；

![image](images/f158961d8eb7d22a27f6344f37daada4.png)

- 审核通过的内容可以正常展示
- 未通过的内容，用户可以在社区个人中心页找到该内容，再次编辑后重新提审

**移动端展示效果**：

![image](images/a0b55f7f0680cfc759dc290e76cc85e6.png)

### 3. 其他操作

#### 强制关闭评论

为文章内容强制关闭评论，强制关闭后，用户无法自主控制评论开关。

#### 编辑星级

内容星级越高，排序时位置越靠前。

#### 批量移动分类

可以多选文章一次性移动到某个分类下。

![image](images/9356e0a0ccfa9e6e8dbfa75a4c9a7e03.png)

#### 强制下架

强制下架后的内容，会强制转为下架状态，并且重新发布强制需要审核，用户在强制下架后重新编辑提审，通过后才会消除强制下架状态。

## 社区配置

**位置**：平台后台 → 营销 → 种草社区 → 社区配置

![image](images/a961cb4872d45ef4f74d5e611b3a0cdc.png)

### 配置说明

| 配置项 | 说明 |
| --- | --- |
| 图文免审核 | 发布图文类型的社区种草时不需要管理员后台审核 |
| 短视频免审核 | 发布短视频类型的社区种草时不需要管理员后台审核 |
| 评论审核 | 用户在对社区种草评论时，是否需要管理员后台审核 |
| 评论开关 | 全局社区种草评论开关，关闭后，所有用户无法评论 |
| 社区状态 | 社区状态在页面设计中进行开启/关闭，DIY页面中不展示入口，即用户无法进入使用 |
