```sql
ALTER TABLE orders ADD INDEX idx_create_time (create_time);
ALTER TABLE order_items ADD INDEX idx_order_id (order_id);

-- 定期维护
OPTIMIZE TABLE orders;
ANALYZE TABLE orders;

-- 备份策略
mysqldump -u root -p crmeb > crmeb_backup_$(date +%Y%m%d).sql
```

```java
// 推荐缓存配置
```

## 常见问题解答

### Q1: CRMEB Java 和 PHP 版本有什么区别？

**A**: 
- **Java 版本**：企业级应用，高性能，扩展性强，适合大型项目
- **PHP 版本**：快速开发，部署简单，适合中小型项目
- **选择**：初创团队选 PHP，融资后做 Java 版本迁移

### Q2: 一个 Java 团队需要多少人维护？

**A**: 
```
初期（0-50 万月销）：1 个全栈开发
中期（50-200 万月销）：2-3 个后端 + 1-2 个前端
大规模（200 万+月销）：专业运维 + DBA + 多个开发
```

### Q3: 如何处理多商户的数据隔离？

**A**:
```
方案1：库隔离 - 每个商户一个数据库
优点：完全隔离，性能最佳
缺点：维护复杂，数据库众多

方案2：表隔离 - 所有商户一个库，表加 shop_id
优点：简单易维护
缺点：性能较差，大规模时需要分库分表

推荐：初期用方案2，月销 500 万后迁移方案1
```
