# 拼团活动说明

嘿！👋 欢迎了解拼团活动功能！

## 一、功能简介

### 应用场景

拼团通过集合多人的购买需求，以更低的价格享受商品或服务，不仅为消费者带来了经济实惠，还促进了商品的快速销售和商家品牌的传播，实现了双赢局面。

**说人话：** 就是大家一起买，价格更便宜！👥

### 活动规则 📋

重要规则说明：

| 规则类型 | 说明 |
|---------|------|
| 💰 不参与分销 | 拼团活动不参与分销 |
| 🎯 不叠加优惠 | 不与积分抵扣、平台优惠券、商家优惠券、付费会员折扣等权益进行叠加 |
| 💵 分账规则 | 用户购买拼团商品，根据商品设置的拼团价进行出售，两方分账按照实际支付金额进行计算，无分销（同秒杀） |
| 🤝 推广关系 | 推广员进行拼团邀请可与参团人员根据平台设置的分销规则绑定分销关系 |

### 活动流程 ✨

**活动创建与审核：**

1. 商家创建拼团活动（支持多个商品一块创建拼团活动）
2. 单个活动商品上限为 **10个**
3. 平台进行拼团活动审核
4. 平台审核通过则在用户端进行展示
5. 支持平台强制关闭已经审核通过的拼团活动

⚠️ **注意：** 平台强制关闭后拼团活动的审核状态变为"已拒绝"，商家可以编辑之后重新提审。

**开团与参团：**

1. **开团用户** 即此条拼团记录的团长
2. 开团之后可以分享给其他人，邀请其他人参与拼团
3. 拼团订单下单之后就会在订单列表-全部中展示为"拼团中"状态

**订单状态说明：**

| 状态 | 说明 | 操作 |
|-----|------|------|
| 🔄 拼团中 | 拼团还未成功 | 不支持商家发货操作（需要隐藏发送货按钮） |
| ✅ 拼团成功 | 达到成团人数 | 该团对应的订单状态全部流转为"待发货" |
| ❌ 拼团失败 | 超时未达成团人数 | 主动发起退款单（仅退款，备注为"拼团失败退款"），该团所有订单状态跟随退款之后流转为"已退款" |

## 二、功能说明

### 2.1 开团 🛒

支持所有用户进行开团操作，用户通过拼团根据拼团价进行购买之后，支持邀请好友参与拼团，达到拼团人数之后，则拼团成功，商家可进行发货等后续操作。

![](./images/6c4d555490b08cf27405dd067ae0d6ee.png)

**举个栗子：** 张三看到一款商品拼团价99元，原价199元，3人成团。张三下单后成为团长，可以邀请好友参团。

### 2.2 邀请好友参团 📱

支持查看自己参与的拼团活动，邀请好友参与拼团，从而达到拼团人数，促进拼团成功。

![](./images/8afb4f8941127a0b9534948d56363f6b.png)

**分享方式：**

支持将拼团列表分享给微信好友或者是朋友圈

![](./images/209c19070f69c47cd438aae8d62f2b04.png)

💡 **小贴士：** 分享到朋友圈可以让更多人看到，拼团成功的几率更高！

### 2.3 参团 👥

支持通过好友分享的拼团进行参团，也支持通过商品详情中的凑团列表，参与他人的拼团活动。

![](./images/c5c41d20458bc28cf51ca96a0471511a.png)

**参团方式：**

- 方式1：通过好友分享的拼团链接参团
- 方式2：在商品详情页查看"凑团列表"，选择其他人的团参与

### 2.4 查看拼团订单 📊

查看拼团订单的操作同查看普通订单记录。

在订单列表中可以看到拼团状态：
- 拼团中：等待其他人参团
- 拼团成功：已达成团人数，等待发货
- 拼团失败：已自动退款

## 常见问题 ❓

**Q1: 拼团失败了怎么办？**
A: 拼团失败会自动退款，款项会原路退回到您的支付账户。

**Q2: 可以同时参加多个拼团吗？**
A: 可以的，每个拼团活动都是独立的。

**Q3: 拼团商品可以使用优惠券吗？**
A: 不可以，拼团活动不与平台优惠券、商家优惠券、积分抵扣等权益叠加使用。

**Q4: 拼团价格怎么分账？**
A: 按照实际支付金额进行分账，不参与分销。
