## 🎯 4 大核心规则

### 规则 1️⃣：流程图 → 纯文本描述

```markdown
❌ 错误：
```
浏览商品 → 加入购物车 → 生成订单
   ↓
商户确认 → 打包发货
```

✅ 正确：
**第一步：用户下单** 浏览商品 → 加入购物车 → 生成订单
**第二步：确认发货** 商户确认 → 打包发货
```

```markdown
✅ 正确：
| 层级 | 说明 |
|------|------|
| 用户界面层 | PC + H5 + App |
```

### 规则 4️⃣：架构图 → 分层文字描述

```markdown
❌ 错误（ASCII 架构图）：
┌───────────────┐
│  用户界面层   │
├───────────────┤
│ PC │ H5 │ APP│
└───────────────┘

✅ 正确（分层描述）：
**第一层：用户界面层**
- PC 管理端（Vue + Element）
- H5 商城（UniApp）
- 小程序和 App（UniApp）

**第二层：后端服务层**
- Admin Service（管理后台）
- Front Service（商城前台）
```
