### 首页推荐设置

自定义首页的商品推荐板块，想加几个加几个。

**Step 1**：点击【添加板块】

![image](images/e77c2636c3b0b39ac05d41de00e2d99a.png)

**Step 2**：配置板块信息

![image](images/24473ad117f528319095216a2f4f66da.png)

| 字段 | 干嘛用的 |
| --- | --- |
| 板块名称 | 显示在 PC 商城的标题 |
| 广告图 | 板块左侧的广告位 |
| 广告图链接 | 点击广告跳哪儿去（选填） |
| 排序 | 数字越小越靠前 |
| 是否开启 | 控制显示/隐藏 |
| 商品 | 选择这个板块展示哪些商品 |

**效果展示**：

![image](images/3e92bc43c0bbb1fd8b9ed11918a4548c.png)

::: tip PC 商城优化小建议
- **Logo** 用透明背景的 PNG，适配各种底色
- **Banner** 尺寸保持一致，不然轮播会跳
- **推荐板块** 不要加太多，3-5 个就够了，用户滚不到底的
- **友情链接** 找相关行业的站交换，别乱加垃圾站
:::
