# 🎀 小红书风格写作规则

> 配合 `CROSS_PLATFORM_FORMAT_RULES.md` 使用，不是替代

## 核心理念

小红书风格的文档应该：
- **亲切感** - 像朋友在聊天，不是教科书
- **鼓励性** - 给读者信心，告诉他们"你可以的"
- **视觉活跃** - 用 emoji 和符号让内容生动
- **实用贴心** - 提示易踩的坑，分享小技巧
- **精准简洁** - 短句子，核心信息突出

---

## 📝 具体规则

### 1. 标题风格

**❌ 错误：**
```
### 1. JDK 安装配置
#### Windows 安装
```

**✅ 正确：**
```
## 🎯 第一步：装 JDK（Java 开发工具包）

### 💻 Windows 用户看这里
```

**规则：**
- 大标题用 emoji + 数字/顺序
- 子标题用场景标识（💻 Windows、🍎 Mac、🐧 Linux）
- 避免生硬的"配置"、"步骤"词汇

---

### 2. 文本表达方式

**❌ 错误：**
```
1. 访问 Oracle Java SE Download 下载 JDK
2. 运行安装程序，选择安装目录（推荐：C:\Program Files\Java\jdk-17.0.x）
3. 配置环境变量
```

**✅ 正确：**
```
1. 点这个链接去 Oracle 官网下 JDK 👉 [Oracle Java SE Download](...)
   💡 小贴士：选 17 或 11 版本就行，别折腾太新的版本了

2. 运行安装程序，选择安装目录
   📂 推荐位置：`C:\Program Files\Java\jdk-17.0.x`
   ⚠️ 路径不要有中文和空格，避免后面各种 bug

3. 配置环境变量（这步容易踩坑，跟紧了！）
   - 打开"系统属性" → "环境变量"
   - 新建系统变量...
```

**规则：**
- 用"点链接"而不是"访问"
- 用"选择X就行"而不是"选择X（推荐）"
- 在操作间隙加入实用建议
- 用 💡 标记小贴士，⚠️ 标记易踩坑的地方
- 关键信息用代码块或加粗突出

---

### 3. 鼓励和过渡语句

**❌ 错误（直接）：**
```
#### macOS/Linux 安装

使用包管理器安装：
```

**✅ 正确（有过渡）：**
```
#### 🍎 Mac 用户和 🐧 Linux 用户

别担心，你们的安装更简单！用包管理器一条命令搞定：
```

**规则：**
- 新章节开始前用一句鼓励的话
- 承认不同用户的不同情况
- 创造"我们一起来"的感觉

---

### 4. 提示框和突出信息

**✅ 推荐格式：**

```markdown
💡 **小贴士**
这是你应该知道的有用信息

⚠️ **容易踩坑**
这是很多人都会出错的地方

✨ **高手玩法**
进阶用户的技巧

🎉 **恭喜！**
完成了重要的一步
```

**规则：**
- 💡 用于实用建议和最佳实践
- ⚠️ 用于常见错误和陷阱
- ✨ 用于高级技巧（可选）
- 🎉 用于里程碑式的完成
- 保持开行，不要写太长

---

### 5. 完成检查和验证

**❌ 错误：**
```
验证安装：
```bash
java -version
```
```

**✅ 正确：**
```
👀 **验证一下有没有装好：**

在命令行输入：
```bash
java -version
```

如果看到版本号就成功了！如果看不到... 往上翻翻，可能是环境变量没设对 😅
```

**规则：**
- 用"验证一下"而不是"验证"
- 说明预期结果
- 如果失败了，给出解决方向
- 保持语气轻松，不要显得严肃

---

### 6. 错误排查部分

**✅ 推荐格式：**

```markdown
### 🔧 常见问题速查

**Q: 我卡在了 npm install 这一步，怎么办？**

很正常，这是大家最常卡的地方！可能是网络问题。

💡 **解决方案：**
1. 换个镜像源试试（推荐淘宝镜像）
2. 或者试试 cnpm
3. 有科学网络的话直接就没事了

**Q: 启动后访问 localhost:3000 显示白屏？**

别慌，这通常是小问题。检查一下：
- API 地址配置对不对？
- 后端服务启动了吗？
```

**规则：**
- 用 Q: A: 对话形式，像朋友聊天
- 先安慰读者"很正常"
- 列出具体解决方案
- 如果有多个原因，用序号清晰列出

---

### 7. 总体结构节奏

一篇文档应该有以下节奏：

```
🎯 开题（激励 + 目标）
  ↓
📋 环境检查（让读者心里有底）
  ↓
🚀 逐步操作（一步一步来，不着急）
  ↓
✅ 验证结果（确认成功）
  ↓
🔧 常见问题（我们都可能遇到）
  ↓
🎉 完成庆祝（你很棒！）
```

## 📝 实例对比

### 完整对比：安装 Node.js

**❌ 传统技术文档风格：**
```
### 4. Node.js 安装配置

#### 使用 NVM 安装（推荐）

macOS/Linux:

1. 安装 NVM
   curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

2. 安装 Node.js 18.x LTS
   nvm install 18
   nvm use 18

3. 验证
   node -v
   npm -v
```

**✅ 小红书风格（配合跨平台规则）：**
```
## 🎯 第四步：装 Node.js（前端开发必需）

你的电脑需要 Node.js 来运行前端代码。别慌，安装很简单！

### 🍎 Mac 和 🐧 Linux 用户（最简单）

用 NVM（Node 版本管理器）来装，以后换版本就不用重新装了：

1. **复制粘贴这条命令到终端：**
   ```bash
   curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
   ```

2. **装 Node.js 18 版本：**
   ```bash
   nvm install 18
   nvm use 18
   ```

💡 **小贴士：** 18 版本是目前最稳定的长期支持版本，适合大多数人

3. **验证一下有没有装好：**
   ```bash
   node -v
   npm -v
   ```

看到版本号就成功了！🎉

### 💻 Windows 用户

你们的安装流程稍微多一步，但也不难：

1. **下载 nvm-windows：** [点这里](https://github.com/coreybutler/nvm-windows/releases)

2. **双击安装程序，一路 Next 就行**

   ⚠️ **注意：** 安装路径别有中文和空格

3. **重启电脑**

   💡 **为什么要重启？** 是为了让系统更新环境变量

4. **打开 PowerShell（管理员模式），运行：**
   ```bash
   nvm install 18.0.0
   nvm use 18.0.0
   ```

5. **验证：**
   ```bash
   node -v
   npm -v
   ```

搞定！一杯咖啡的时间就装好了 ☕

### 💻 直接安装（不想用 NVM）

如果上面的方法太复杂，也可以直接装：

👉 [Node.js 官网](https://nodejs.org/) 下载 LTS 版本，一直 Next 就行

⚠️ **但是要注意：** 以后要换版本的话得全部卸载重装，NVM 就方便多了
```

## ✅ 应用检查清单

在完成每篇文档时，检查：

- [ ] 大标题有 emoji 和目标说明
- [ ] 每个重要步骤前有鼓励的过渡句
- [ ] 有 💡 小贴士标记
- [ ] 有 ⚠️ 容易踩坑的提醒
- [ ] 验证步骤说明预期结果和失败时怎么办
- [ ] 错误排查用 Q&A 格式
- [ ] 完成时有 🎉 的庆祝感
- [ ] 语气亲切，像朋友在聊天
- [ ] 没有"配置、安装、设置"这样生硬的词
- [ ] 代码块和关键信息都突出了
