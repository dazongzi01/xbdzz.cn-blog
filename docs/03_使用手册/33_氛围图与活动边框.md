# 氛围图与活动边框

> 给商品穿个「节日限定皮肤」，让用户一眼就知道：这波有活动！

## 氛围图

氛围图是叠加在商品详情主图上的装饰层，用来营造活动氛围。比如双11、618、年货节，给商品主图加个「狂欢倒计时」「限时特惠」之类的角标。

**本质就是**：给商品详情页的主图 P 个图，但不用改原图，随时上随时撤。

**路径**：平台端 → 营销 → 氛围图

![image](images/a61afe670f9295e7e80b53f0e75ca156.png)

### 怎么操作

**Step 1**：点击添加

![image](images/1c369dd7b64da664466ec738fbb9b1fd.png)

**Step 2**：配置活动信息

填写活动名称、展示时间区间、上传氛围图素材

![image](images/0d57f3fc13127d447ee106dcfb99af84.png)

**Step 3**：选择要展示氛围图的商品

支持多种选择方式：
- 全部商品（简单粗暴）
- 指定商品（精准投放）
- 按分类选
- 按商户选
- 按品牌选

![image](images/a8f330a8875e5c3f680701236c4a2b91.png)

## 活动边框

边框图和氛围图类似，区别在于：
- **氛围图**：出现在商品详情页的主图上
- **边框图**：出现在商品列表页的商品卡片上

用户在浏览列表的时候，一眼就能看到哪些商品在搞活动。视觉冲击力更强，点击率往往更高。

**路径**：平台端 → 营销 → 活动边框

![image](images/a3760d6afdd73e4ec55bc3bb3bf055a1.png)

### 操作流程

**Step 1**：添加边框图

![image](images/93d8a4c47c76d8ffef168f700d2f81c9.png)

**Step 2**：填写活动名称、时间、上传边框素材

![image](images/91206568b1e49055dd7d9f9057947d06.png)

**Step 3**：选择参与商品

和氛围图一样，支持全选、指定、按分类、按商户、按品牌。

![image](images/073d1fbda81a8c33e26971d4030c87e2.png)

::: tip 运营小技巧
- 氛围图和边框图可以同时用，详情页和列表页双重轰炸
- 设置好结束时间，活动结束自动撤掉，不用手动清理
- 大促期间可以按品牌/商户分批设置，不同商家不同风格
:::
