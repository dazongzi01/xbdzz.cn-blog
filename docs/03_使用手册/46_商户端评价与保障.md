# 商户端评价与保障

> 好评是销量的助推器，保障是信任的敲门砖 ⭐

## 商品评价管理

> 用户说好话要回复，说坏话更要回复 💬

### 这是干嘛的？

管理用户对商品的评价，支持回复、删除评价，还能添加自评给商品「打气」。

**路径**：商户后台 → 商品 → 商品评价

![评价管理列表](./images/62861775cd16137abe9bdfd1dd9d5c47.png)

---

### 筛选功能

| 筛选项 | 说明 |
| --- | --- |
| 用户搜索 | 输入昵称、用户ID、手机号精确筛选 |
| 时间选择 | 按日期范围查询评价 |
| 回复状态 | 已回复 / 未回复 |
| 评价星级 | 1-5 星筛选 |
| 商品搜索 | 输入商品关键词定位相关评价 |

---

### 评价列表字段

| 字段 | 说明 |
| --- | --- |
| 商品信息 | 被评价的商品名称 |
| 用户昵称 | 评价者昵称 |
| 评价星级 | 1-5 星（数字展示） |
| 评价内容 | 用户评论原文 |
| 回复内容 | 商家回复内容 |
| 评价时间 | 按时间倒序排列，最新置顶 |

---

### 回复评价

> 及时回复评价，让用户感受到被重视 🤝

![回复评价](./images/49cf708c960f3c558c3e9c8381b3d457.png)

::: tip 回复技巧
- **好评**：感谢支持 + 欢迎下次光临
- **中评**：感谢反馈 + 说明改进措施
- **差评**：诚恳道歉 + 提供解决方案 + 邀请私聊处理
:::

---

### 删除评价

对于无效或违规评价，可以删除（需二次确认）。

![删除评价](./images/2658deb6d1b509920d0a9450e0cf5206.png)

::: warning 慎用删除
频繁删除差评会影响店铺可信度，建议优先通过回复和售后解决问题。
:::

---

### 添加自评

> 新品没评价？自己先来几条破冰 🧊

![添加自评](./images/8b4a94800e6ea8b773ac65f514f1179b.png)

::: tip 自评小技巧
- 模拟真实用户语气，别太官方
- 突出商品卖点和使用体验
- 适当加点小瑕疵更显真实

## 保障服务组合

> 「7天无理由」「正品保证」这些标签，能让用户更敢下单 🛡️

### 这是干嘛的？

将多个保障服务打包成组合，添加商品时一键选用，省时省力。

**路径**：商户后台 → 商品 → 保障服务组合

![保障服务组合列表](./images/a54b0b6653c3100534a374960020285f.png)

::: tip 保障服务来源
保障服务由**平台端**统一维护，商户只能选用，不能自己创建。
:::

---

### 添加保障服务组合

**Step 1**：点击【添加保障服务组合】

![添加组合按钮](./images/3b63d47866dfec3e82309bc2982019e3.png)

**Step 2**：填写组合名称，选取多个保障服务

![填写组合信息](./images/d3b4d338d4e3ae7f8127044609b80e94.png)

**Step 3**：点击【确定】完成添加

#### 字段说明

| 字段 | 说明 |
| --- | --- |
| 组合名称 | 用于区分不同组合，如「数码商品保障」「食品安全保障」 |
| 选取保障服务 | 从平台维护的保障服务中多选 |

---

### 查看组合详情

点击【详情】查看组合中包含的保障服务条款。

![查看详情](./images/e391f9da47b80e054fa303ecfac824ea.png)

---

### 编辑组合

![编辑组合](./images/b299ff5f0f2b5b94818df03e6b0b54ae.png)

::: warning 注意
修改组合后，**已关联此组合的商品不会同步更新**，保留原有保障服务。
:::

---

### 删除组合

![删除组合](./images/c8d8d2b75ccb512f7eca258e0c7350f6.png)

::: tip
删除组合后，已使用该组合的商品仍会保留之前选中的保障服务。
:::

---

### 商品中使用保障服务

添加商品时，可以选择两种方式：

**方式一**：直接选择保障服务组合（一键添加多个）

![选择组合](./images/ed986ca2b3278f915530ecaa904a905f.png)

**方式二**：手动多选单个保障服务

![手动选择](./images/fa418902a51b4e8bb44521a4b206bc54.png)

## 最佳实践

### 评价管理策略

| 评价类型 | 处理建议 |
| --- | --- |
| ⭐⭐⭐⭐⭐ 好评 | 24h 内回复，表达感谢 |
| ⭐⭐⭐ 中评 | 主动询问不满原因，提供补偿 |
| ⭐ 差评 | 第一时间联系用户，解决问题后引导追评 |
| 恶意差评 | 收集证据，联系平台申诉 |

### 保障服务推荐组合

| 商品类型 | 推荐保障 |
| --- | --- |
| 数码产品 | 正品保证、7天无理由、全国联保 |
| 服装鞋帽 | 7天无理由、运费险、假一赔十 |
| 食品生鲜 | 新鲜保证、坏果包赔、极速退款 |
| 家电家具 | 正品保证、送货上门、免费安装 |

::: tip 转化率提升秘籍
有保障服务的商品，转化率平均提升 **15%-30%**！别偷懒，该加的都加上。
:::
