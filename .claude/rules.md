## 对话语言设置

**所有与我的对话都使用中文进行**

- 优先使用简体中文

## 📝 文档写作规范

### 禁止内容

在编写或生成文档时，**严格禁止**包含以下内容：

#### ❌ 品牌名称限制
- **绝对禁止使用 "CRMEB" 或 "crmeb" 等任何形式的该品牌名称**
- 不要在文档、代码注释、配置文件中出现
- 不要在图片、截图、示例中出现
- 替代方案：使用"系统"、"商城系统"、"平台"等通用名称

#### ❌ 联系方式
- 不要添加客服电话
- 不要添加技术支持电话
- 不要添加联系电话/手机号码
- 不要添加QQ/微信等即时通讯号码

#### ❌ 客服信息
- 不要添加"联系客服"相关内容
- 不要添加"技术支持"联系方式
- 不要添加"在线客服"链接
- 不要添加客服邮箱

#### ❌ 时间戳和版本信息
- 不要添加文档创建时间
- 不要添加文档更新时间
- 不要添加"最后更新"时间
- 不要添加版本发布日期
- 不要添加文档版本号（如 v2.1）
- 不要添加维护者信息
- 不要添加作者信息

### 💬 语言风格规范

#### 1. 开场白要亲切

**推荐：**
```markdown
> 嘿！👋
> 这可能是整个系统里最复杂的部分了 - 涉及到钱的问题总是这样。
> 但别怕，我们用最简单的方式给你讲明白！
```

**避免：**
```markdown
本文档介绍订单支付系统的计算规则。
```

#### 2. 用口语化表达

**推荐的表达方式：**
- "说人话：xxx"
- "简单来说：xxx"
- "别怕，跟着这份指南一步一步来"
- "搞定！🎉"
- "太棒了！"
- "举个栗子 🌰"
- "敲黑板！"（强调重点）
- "重头戏来了！"

**避免的表达：**
- "本系统采用..."
- "根据业务需求..."
- "实现方式如下..."
- 过于正式的书面语

#### 3. 使用引用块增加趣味

**💡 小贴士类：**
```markdown
> **💡 小贴士：** 环境变量就是告诉系统在哪里找 Java，别漏了这步！
```

**⚠️ 注意类：**
```markdown
> **⚠️ 注意：** 运费不参与分账分润！这个很重要，记住了
```

**💬 解释类：**
```markdown
> **💡 为什么这样设计？**
> 因为平台和商家各自承担自己的优惠成本，互不干扰。
```

**🎯 总结类：**
```markdown
> **💡 说人话：** 活动商品就是"一口价"，别指望还能再优惠
```

#### 4. 用比喻和类比

**推荐的比喻：**
- "把顾客变粉丝"
- "分蛋糕"（分账）
- "一口价"（活动商品）
- "解放双手"
- "一目了然"
- "开箱即用"

### 📋 结构规范

#### 1. 用表格展示对比信息

**术语解释表：**
```markdown
| 术语 | 通俗解释 | 举个栗子 🌰 |
|------|---------|-----------|
| **商品活动价** | 参加活动时的特殊价格 | 秒杀价 99 元（原价 199） |
```

**功能对比表：**
```markdown
| 订单状态 | 能退款吗 | 退款方式 |
|---------|---------|---------|
| **待支付** | ❌ 不能退 | - |
| **待发货** | ✅ 只能"仅退款" | 直接退钱 |
```

#### 2. 用代码块展示流程

**计算流程：**
```markdown
💵 商品售价
    ⬇️
🎟️ 减去商家优惠券
    ⬇️
🎟️ 减去平台优惠券
    ⬇️
💰 = 订单实付
```

**分支流程：**
```markdown
用户申请退款
    ⬇️
商家审核
    ⬇️
   ╱ ＼
 同意  拒绝
  ⬇️    ⬇️
已退款  未退款
```

#### 3. 完整案例演示

对于复杂的计算，必须提供完整案例：

```markdown
### 📊 完整案例

**假设：**
\```
📦 订单内容：
- 商品 A：100 元 × 2 件

🎟️ 使用优惠：
- 平台优惠券：30 元
\```

#### 💳 第一步：计算订单实付

\```
商品总价 = 100 × 2 = 200 元
订单实付 = 200 - 30 = 170 元
\```

**用户支付：170 元** ✅
```

### 🎯 具体写作模式

#### 名词解释模式

```markdown
## 📖 名词解释（别被专业术语吓到）

这部分很重要！搞懂这些术语，后面就轻松了。

### 💵 价格相关

| 术语 | 通俗解释 | 举个栗子 🌰 |
|------|---------|-----------|
| **商品售价** | 商家设定的正常售价 | 商家标价 199 元 |
```

#### 规则说明模式

```markdown
## 🎯 规则说明（游戏规则要讲清楚）

### 🎟️ 优惠券能不能叠加？

#### ✅ 可以叠加

**简单来说：** 一个订单可以用 1 张平台券 + 每个商家 1 张商家券

**举个例子：**
\```
📦 你的购物车：
- A 店铺：一件衣服 100 元
\```

> **💡 为什么这样设计？**
> 因为平台和商家各自承担自己的优惠成本。
```

#### 技术细节模式

```markdown
## 💳 订单支付详解（重头戏来了！）

### 🛒 普通订单怎么算钱？

#### 计算公式（敲黑板！）

\```
订单实付 = 商品售价 - 优惠券 + 运费
\```

**注意：** 计算结果保留两位小数后**舍去**

> **💡 举个例子：**
> - 商品总价 200 元
> - 积分抵扣金额 = 200 × 10% = 20 元
```

#### 总结模式

```markdown
## 🎯 总结（记住这些就够了）

### ✅ 关键要点

1. **💰 计算顺序** - 售价 → 商家券 → 平台券 → 积分
2. **🎟️ 优惠券叠加** - 1 张平台券 + 每店 1 张商家券

### 🧮 常用公式速查

\```
订单实付 = 商品售价 - 商家券 - 平台券 + 运费
\```

### 💡 最后的建议

1. **先理解原理** - 别死记公式
2. **看实际案例** - 代入数字算一遍

> **🎉 恭喜你读到这里！**
> 有问题随时查阅这份文档 💪
```
