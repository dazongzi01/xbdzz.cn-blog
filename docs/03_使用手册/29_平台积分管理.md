# 平台积分管理

## 积分活动说明

### 一、活动介绍

积分主要用户在商城下单时，抵扣对应的支付金额；积分可以通过下单、签到获取。因此积分在商城中起到了激励用户消费、提高用户忠诚度、增加用户参与度的作用，对商城运营和销售有一定的推动作用。

### 二、功能说明

#### 2.1 获取积分

获取积分渠道：签到、下单赠送

1. **签到**：用户通过签到可以获得相应的积分，签到获得积分数量设置见签到配置。
2. **下单赠送**：用户下单付款之后，根据积分配置中「下单赠送积分（实际支付多少元赠送1积分）」进行配置；根据开始冻结规则及积分冻结时长到达解冻时长之后进行解冻发放。

#### 2.2 积分使用

积分使用方式：下单积分抵扣，可以减少实际支付金额

#### 2.3 查看积分

用户可以查看自己的当前积分、累计积分、累计消费积分，以及积分获取、使用明细。

![image](images/5066d959d4e2233f93a1b44d3f8e0dbe.png)

#### 2.4 积分抵扣规则

1. 积分抵扣支持与平台优惠券、商家优惠券进行叠加使用，秒杀等营销活动不支持使用积分抵扣
2. 订单中使用的积分抵扣金额，由平台承担
3. 商品售价减去平台优惠券与商家优惠券之后高于积分抵扣开启金额，则可使用积分抵扣
4. 商品售价减去平台优惠券与商家优惠券之后，再去计算积分抵扣比例，积分抵扣比例支持平台自定义设置
5. 用户下单之后，赠送积分会根据平台设置的冻结期进入冻结，待冻结期过了没有发生售后相关情况，积分给予用户解冻；若冻结期间发生售后，冻结积分会进行收回；若解冻之后发生售后，已解冻积分不进行收回，损失由平台承担

## 积分配置

功能简述：积分配置主要用于积分抵扣开关、积分冻结时间、抵扣金额、抵扣比例等相关设置。

::: warning 注意
积分抵扣金额由平台承担
:::

根据下图路径进入积分配置页面：

![image](images/203e38a9893243f699a109d4b2bd655e.png)

### 配置字段说明

| 字段名称 | 字段说明 |
| --- | --- |
| 积分抵扣金额（元） | 1积分抵扣多少金额；用户下单时可以使用积分优惠 |
| 积分抵扣比例（%） | 订单中积分可抵扣商品金额比例（0~100）%；使用积分的限制调整，辅助平台在运营营收平衡 |
| 积分抵扣开启金额（元） | 订单满多少元可以使用积分抵扣；积分抵扣门槛设置 |
| 下单赠送积分（元） | 实际支付多少元赠送1积分 |
| 开始冻结规则 | 开始冻结节点的选择，支持：订单支付后、订单收货后、订单完成后 |
| 积分冻结时间（天） | 根据开始冻结规则中选择的节点，过了冻结时长之后，系统会根据下单赠送积分进行积分赠送；但是由于异常订单退款等可能会产生平台损失，因此通过积分冻结时间来尽量避免这种异常情况 |
| 积分抵扣 | 开启/关闭，关闭之后，下单不可使用积分抵扣 |
