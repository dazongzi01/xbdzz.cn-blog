## 🚀 快速开始

### 第1步：启动开发服务器

```bash
npm run dev
```

服务器将在 `http://localhost:5175/` 启动

### 第2步：访问文档并激活工具栏

在浏览器地址栏的 URL 后面添加 `?dazongzi=666`：

```
http://localhost:5175/01_初步了解/01_快速了解?dazongzi=666
```

**⚠️ 注意：必须带上这个魔法参数才能看到平台工具栏！**

### 第3步：看到工具栏

页面右上角会出现平台按钮工具栏：

```
┌────────────────────────────┐
│ 📢 一键复制到多平台        │
├────────────────────────────┤
│ 📱 微信公众号  ⚡ 掘金     │
│ 📝 CSDN      🎓 知乎      │
└────────────────────────────┘
```

### 第4步：点击平台按钮预览

点击任意平台按钮（例如 📱 微信公众号）：

- 🎨 弹出预览窗口
- 📋 显示该平台的格式化效果
- ✅ 所见即所得预览

### 第5步：复制到剪贴板

预览窗口中点击「📋 复制全文」按钮：

- ✨ 自动复制格式化内容到系统剪贴板
- 🎯 保留所有样式和排版

### 第6步：粘贴到目标平台编辑器

1. 打开目标平台的编辑器
   - 微信公众号后台
   - 掘金编辑器
   - CSDN 发布器
   - 知乎创作中心

2. 在编辑框中 `Cmd+V` (Mac) 或 `Ctrl+V` (Windows) 粘贴

3. 完成！✅

## 💡 使用技巧

### ✨ 如何快速启用多个浏览器窗口？

1. 在主浏览器中打开文档 + `?dazongzi=666`
2. 在其他窗口打开各平台的编辑器
3. 一个窗口预览，另一个窗口编辑，效率翻倍！

### 📋 复制失败怎么办？

如果自动复制失败（某些浏览器限制），可以：

1. 在预览窗口中手动全选（`Cmd+A` / `Ctrl+A`）
2. 手动复制（`Cmd+C` / `Ctrl+C`）
3. 粘贴到目标平台（`Cmd+V` / `Ctrl+V`）

### 🔄 修改内容后如何更新预览？

1. 关闭预览窗口
2. 修改文章内容
3. 刷新浏览器或重新点击平台按钮
4. 重新预览和复制

### 🎯 如何在不同平台间切换？

- 不需要重新生成，直接点击其他平台按钮
- 所有格式会自动转换
- 可以对比不同平台效果

## 🔧 技术架构

### 核心文件

- **`docs/.vitepress/theme/components/PlatformToolbar.vue`** - 工具栏组件
- **`docs/.vitepress/theme/utils/formatters.ts`** - 样式转换工具
- **`docs/.vitepress/theme/index.ts`** - VitePress 主题注册

### 关键实现

1. **URL 参数检测** - `?dazongzi=666` 激活工具栏
2. **DOM 内容提取** - 支持多种元素选择器
3. **正则表达式样式注入** - 为各标签添加平台样式
4. **内联 CSS** - 每个标签携带完整样式
5. **Clipboard API** - 一键复制到剪贴板

## 📝 常见问题

### Q1: 为什么必须加 `?dazongzi=666` 参数？

A: 这是一个"魔法参数"，用于激活多平台工具。普通访问不显示工具栏，只有加上这个参数才会出现。这样可以避免干扰文档的正常阅读体验。

### Q2: 复制后粘贴到其他平台没有样式怎么办？

A: 这可能是浏览器或平台限制。可以尝试：
- 换一个浏览器试试
- 手动复制而不是点击按钮复制
- 联系平台客服

### Q3: 能否自定义平台样式？

A: 可以！编辑 `docs/.vitepress/theme/utils/formatters.ts` 中的 `platformStyles` 对象，修改相应平台的 CSS 样式即可。

### Q4: 支持添加新的平台吗？

A: 完全支持！步骤如下：

1. 在 `formatters.ts` 中的 `platformStyles` 对象添加新平台的样式
2. 添加对应的格式化函数 `export function formatFor新平台名()`
3. 在 `PlatformToolbar.vue` 中的 `platformNames` 和 `formatters` 对象添加新平台
4. 保存即可自动生效

### Q5: 为什么某些样式在复制后丢失了？

A: 这可能是目标平台的编辑器不支持某些 CSS 属性。我们已经针对各平台优化了样式，但如果仍有问题：
- 检查目标平台的样式要求
- 修改 `formatters.ts` 中对应的样式配置
- 重新测试
