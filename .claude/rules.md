# Claude Code 项目规则

## 对话语言设置

**所有与我的对话都使用中文进行**

- 优先使用简体中文
- 代码注释可保持原语言或翻译为中文
- 变量名和函数名保持原样，不翻译
- 文档和输出信息使用中文

## 项目背景

这是一个 CRMEB 文档采集和发布系统，包含：
- VitePress 文档站点
- 多平台内容发布（WeChat, Juejin, CSDN, Zhihu）
- Web 爬虫采集系统
- 自动路径生成和分类

## 主要特性

- 支持模块和章节划分

- 自动提取网页标题

### 3. 工作流程指南 (COLLECTION_WORKFLOW.md)
- 详细的使用步骤
- 常见问题解决
- 最佳实践

## 与用户沟通时

1. **代码示例**：用中文解释，代码保持原样
2. **文件操作**：详细说明文件路径和操作步骤
3. **错误处理**：用中文清晰地解释问题和解决方案
4. **技术术语**：可使用中英混合，保证清晰理解

## 📝 文档写作规范

### 禁止内容

在编写或生成文档时，**严格禁止**包含以下内容：

#### ❌ 品牌名称限制
- **绝对禁止使用 "CRMEB" 或 "crmeb" 等任何形式的该品牌名称**
- 不要在文档、代码注释、配置文件中出现
- 不要在图片、截图、示例中出现
- 替代方案：使用"系统"、"商城系统"、"平台"等通用名称

#### ❌ 联系方式
- 不要添加客服电话
- 不要添加技术支持电话
- 不要添加联系电话/手机号码
- 不要添加QQ/微信等即时通讯号码

#### ❌ 客服信息
- 不要添加"联系客服"相关内容
- 不要添加"技术支持"联系方式
- 不要添加"在线客服"链接
- 不要添加客服邮箱

#### ❌ 时间戳
- 不要添加文档创建时间
- 不要添加文档更新时间
- 不要添加"最后更新"时间
- 不要添加版本发布日期

### 文档结尾规范

**正确示例：**
```markdown
---

## 最佳实践

1. 建议先测试再上线
2. 定期备份配置信息
3. 注意数据安全

---
```

**错误示例（不要使用）：**
```markdown
❌ *最后更新时间：2025-12-03*
❌ *创建时间：2025-11-01*
❌
❌ ## 📞 技术支持
❌
❌ 如需更多帮助，请联系：
❌ - 📧 技术支持邮箱
❌ - 💬 在线客服
❌ - 📱 技术支持热线：xxx
```

### 替代方案

如果需要提供帮助信息，使用以下方式：

```markdown
---

## 获取帮助

如有疑问，请参考：
- 📚 查看其他相关文档
- 🔍 搜索常见问题解答
- 📖 阅读官方使用手册
```

在提交文档前，确保：
- ✅ 文档中没有电话号码
- ✅ 文档中没有客服相关信息
- ✅ 文档中没有时间戳
- ✅ 文档结尾简洁专业
