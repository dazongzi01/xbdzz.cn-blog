# CRMEB 多商户 Java 系统 - 快速了解指南

## 一句话定义

CRMEB 是一套基于 Java SpringBoot + Vue + UniApp 构建的企业级新零售移动电商系统，集客户关系管理与营销电商于一体，支持 PC、H5、小程序、App 多端部署，特别适合企业二次开发。

---

## 系统概览

### 什么是 CRMEB？

CRMEB 是西安众邦网络科技有限公司旗下的产品，经过 **8 年的技术沉淀和行业积累**打造的企业级电商解决方案。系统名称本身就代表了其核心价值：**CRM（客户关系管理）+ EB（电商系统）**。

**核心特点：**
- ✅ 完整的电商功能体系（商品、订单、支付、物流等）
- ✅ 深度的客户管理能力（会员、积分、标签、分群等）
- ✅ 强大的营销工具（促销、优惠券、返利、分销等）
- ✅ 支持多端部署（PC 管理平台、H5、小程序、App）
- ✅ 高度可定制（为企业二次开发优化）

## 核心功能模块

### 1. 电商交易模块

**完整的在线购物流程：**

```
浏览商品 → 加入购物车 → 生成订单 → 选择支付 → 支付成功
   ↓
商户确认 → 打包发货 → 物流配送 → 买家收货 → 订单完成 → 评价反馈
```

**具体功能：**
- 商品管理：分类、规格、库存、价格
- 购物车：实时更新、库存锁定、智能推荐
- 订单管理：订单查询、状态追踪、订单统计
- 支付方式：支付宝、微信支付、余额支付、银行卡
- 物流配送：快递单号自动生成、物流追踪、自动签收
- 退货退款：退货申请、审核流程、原路退回

### 2. CRM 客户管理模块

**深度的客户关系管理：**

```
新客户注册 → 自动分级 → 行为追踪 → 数据分析 → 精准营销 → 转化复购
```

**具体功能：**
- **客户档案**：基本信息、消费历史、客户画像、黑名单管理
- **会员系统**：等级体系（普通/黄金/铂金）、积分规则、充值卡、优惠券
- **客户分群**：按消费额、购买频率、地区等自动分群
- **互动管理**：站内信、短信通知、邮件通知、客服工作台
- **数据分析**：消费趋势、活跃度、流失预警、LTV 分析

### 3. 营销推广模块

**强大的营销工具集：**

| 营销类型 | 功能 | 效果 |
|---------|------|------|
| **秒杀** | 限时限量、自动结束 | 快速成交、制造紧迫感 |
| **拼团** | 多人拼团、阶梯价格 | 增加复购、社交传播 |
| **砍价** | 邀请砍价、分享得利 | 社交裂变、获取新客 |
| **折扣** | 限时折扣、分类折扣 | 清库存、促进购买 |
| **返利** | 三级分佣、自动计算 | 激励分销、扩大销售 |
| **优惠券** | 多种面额、自动发放 | 提升转化、精准营销 |

### 4. 支付结算模块

**完整的财务管理体系：**

**交易链路：**
```
订单金额 = 商品价格 + 运费 - 优惠券 - 积分兑换 + 其他费用
   ↓
用户支付 → 支付成功 → 平台到账 → 计算佣金 → 商户结算
   ↓
对账单 → 提现审核 → 打款到账 → 交易完成
```

**结算功能：**
- 多种支付方式集成
- 自动佣金计算（支持多商户场景）
- 对账单生成和下载
- 提现管理和审核
- 财务报表和统计

### 5. 数据分析模块

**经营决策数据化：**

**销售分析：**
- 日/周/月销售额趋势
- 商品销量排行
- 客户转化漏斗
- 平均客单价

**客户分析：**
- 新客户增长
- 客户留存率
- 复购率分析
- 客户生命周期价值（LTV）

**运营指标：**
- 流量来源分析
- 转化率统计
- 退货率追踪
- 评价评分统计

**必需：**
- 公众号：服务号（已认证 + 开通支付功能）

**可选：**

**说明：** 公众号和小程序可分开配置，支持渐进式集成

## 常见问题

**Q: CRMEB 和其他电商系统有什么区别？**

A: CRMEB 的核心优势是 **CRM + 电商深度融合**。不只是卖货，而是全周期管理客户。同时支持多端部署（小程序、App 等），开发成本更低。

**Q: 需要多少人维护？**

A:
- 初期（0-50 万月销）：1 个全栈开发
- 中期（50-200 万月销）：2-3 个后端 + 1-2 个前端
- 大规模（200 万+）：专业运维团队

**Q: 可以支持多少商户？**

A: 理论上无限制。但实际需要根据服务器配置优化：
- 4H 8G：100+ 商户
- 8H 16G：1000+ 商户
- 16H+ 32G+：10000+ 商户

**Q: 微信支付怎么配置？**

A: 需要 3 步：
1. 企业申请微信支付账户
2. 在 CRMEB 后台填写 AppID、MchID、API Key
3. 配置支付回调地址
4. 测试验证

**Q: 可以修改源码吗？**

A: 可以。购买源码后，可自由修改和扩展。建议建立自己的分支管理。

**Q: 升级新版本怎么办？**

A:
- 保存自定义修改到本地分支
- 更新官方版本
- 合并自定义代码
- 测试验证后上线
