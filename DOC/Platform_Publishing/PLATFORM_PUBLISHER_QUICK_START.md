# 🚀 多平台发布工具 - 快速开始

> 写一次，发布到 4 个平台！📱 微信 ⚡ 掘金 📝 CSDN 🎓 知乎

---

## ⚡ 30 秒快速开始

### 1️⃣ 启动服务器（如果还没启动）
```bash
npm run dev
```

### 2️⃣ 打开任意文档并激活工具栏

在浏览器地址栏输入：
```
http://localhost:5175/01_初步了解/01_快速了解?dazongzi=666
```

**关键：必须加 `?dazongzi=666` 参数！**

### 3️⃣ 看到右上角的工具栏

```
┌────────────────────────────┐
│ 📢 一键复制到多平台        │
├────────────────────────────┤
│ 📱 微信公众号  ⚡ 掘金     │
│ 📝 CSDN      🎓 知乎      │
└────────────────────────────┘
```

### 4️⃣ 点击你要发布的平台

比如点击 **📱 微信公众号**

### 5️⃣ 预览后点击「📋 复制全文」

自动复制到你的剪贴板！

### 6️⃣ 打开目标平台编辑器，粘贴即可

- 微信公众号后台
- 掘金编辑器
- CSDN 发布页
- 知乎编辑器

**完成！** ✅
