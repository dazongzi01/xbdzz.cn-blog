💾 【爬虫快速使用】

安装依赖：
  $ cd crawler
  $ pip install -r requirements.txt

查看配置：
  $ cat config.json

修改配置：
  • base_url: 你的网站 URL
  • start_url: 爬虫起始点

运行爬虫：
  $ python spider.py

查看输出：
  $ ls output/
  output/
  ├─ structure.json      (文档结构树)
  ├─ crawl_report.json   (爬虫报告)
  ├─ images/             (下载的图片)
  └─ module-name/        (转换的 Markdown)
