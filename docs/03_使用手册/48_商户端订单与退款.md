# 商户端订单与退款

> 订单是钱的入口，退款是口碑的出口，两手都要抓 💰

## 订单管理

> 从下单到收货，每一步都要盯紧 📦

### 这是干嘛的？

商户端订单管理展示店铺的所有成交订单，包括普通订单、秒杀订单、视频号订单等，支持发货、核销、打印小票等操作。

**路径**：商户后台 → 订单 → 订单列表

![订单列表](./images/511cf351bbe06cd33b772ccdcb3a0165.png)

::: warning 发货前必读
订单发货之前，需要先添加本店铺合作的物流公司！
:::

### 订单发货

#### 方式一：整单物流发货

一个包裹发完所有商品。

**Step 1**：点击【发货】按钮

![发货按钮](./images/90e3740e5a475222506370ee2dd1f854.png)

**Step 2**：选择快递公司，填写快递单号，点击【提交】

![整单发货](./images/9820a0eef9f43fb72a2b4cfaeb51236e.png)

#### 方式二：分单物流发货

多件商品分开发货，一个订单多个包裹。

**Step 1**：开启「分单发货」开关

**Step 2**：选择要发货的商品和数量

![分单发货](./images/f4b88799353ec632f20795c74d69388c.png)

#### 方式三：无需发货

适用于虚拟商品或特殊情况。

![无需发货](./images/556af2d3fc35e8e02360e0da211c79c4.png)

填写备注说明，用户端可查看。

#### 方式四：商家送货

商家自己配送，填写配送员信息。

![商家送货](./images/f559f9db2a7c1b4d6d96b14bf2eafc99.png)

### 直接退款

> 商家主动退款，不用等用户申请 💸

![直接退款](./images/649dcb0e778dcd8f9e94dedcd9f20a42.png)

#### 整单退款

选择整单退款，一次性退完。

![整单退款](./images/a353887ff4da9871b607ca93e3089aa1.png)

#### 分单退款

选择部分商品退款。

![分单退款](./images/b81eb2a22000558c8b522eb090d7e843.png)

| 字段 | 说明 |
| --- | --- |
| 总数 | 购买数量 / 已发货数量 / 可退款数量 |
| 可退总额 | 该 SKU 剩余可退金额 |
| 退款数量 | 本次退款数量 |
| 预计退款金额 | 仅供参考，以实际为准 |

::: danger 注意
退款后不能撤回！请谨慎操作。
:::

## 退款单管理

> 用户申请退款，商家审核处理 🔄

### 退款类型

| 类型 | 流程 | 说明 |
| --- | --- | --- |
| 仅退款 | 用户申请 → 商家同意 → 退款完成 | 无需退货 |
| 退货退款 | 用户申请 → 商家同意 → 用户退货 → 商家确认收货 → 退款完成 | 需要退货 |

### 仅退款流程图

```
用户发起申请 → 商家审核
                ├── 同意 → 退款原路返回 ✅
                └── 拒绝 → 退款关闭 ❌
```

### 退货退款流程图

```
用户发起申请 → 商家审核
                ├── 同意 → 用户填写退货物流 → 商家确认收货
                │                              ├── 确认 → 退款原路返回 ✅
                │                              └── 拒绝 → 退款关闭 ❌
                └── 拒绝 → 退款关闭 ❌
```

### 退款审核

#### 同意退款

![同意退款](./images/89ca15ca677c2b02e980b8ae4289fa65.png)

- 仅退款：同意后直接原路退款
- 退货退款：同意后等待用户退货

#### 拒绝退款

![拒绝退款](./images/be0df84d874c9918eaa40c0d8440b10d.png)

需要填写拒绝原因。

::: tip
退货退款类型，商家同意后用户 **7 天内未提交退货信息**，系统自动撤销售后单
:::

## 平台退款单

> 平台视角，可以强制退款 👮

**路径**：平台后台 → 订单 → 退款单

![平台退款单](./images/1c135a4f9c24a806e087f77bb7cb1e3d.png)

### 平台备注

平台可以对退款单添加备注，商家可见，用户不可见。

![平台备注](./images/643d6b76a060d6833a3a8ea4c28900db.png)

### 平台强制退款

当出现以下情况，平台可以介入强制退款：
- 商家迟迟不审核
- 用户已退货但商家不确认收货
- 商家与用户存在纠纷

![强制退款](./images/d1c62d4fe7ccdfacfa234660fe3d7c78.png)

::: danger 警告
强制退款不可逆！无论用户是否收到货物，都会原路返回退款。
:::

## 最佳实践

### 发货效率提升

| 技巧 | 说明 |
| --- | --- |
| 提前添加物流公司 | 避免发货时现找 |
| 使用电子面单 | 自动填写单号 |
| 批量发货 | 多订单一起处理 |

### 退款处理原则

| 场景 | 建议处理方式 |
| --- | --- |
| 未发货退款 | 直接同意 |
| 质量问题 | 同意退货退款，主动道歉 |
| 用户不想要了 | 协商运费承担后同意 |
| 恶意退款 | 收集证据，拒绝并说明理由 |

::: tip 降低退款率的秘诀
1. 商品描述要真实，避免过度美化
2. 发货前检查商品质量
3. 包装要结实，防止运输损坏
4. 及时回复用户咨询，减少误购
:::
