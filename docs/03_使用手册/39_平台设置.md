### 订单配置 📦

![image](images/34e3b18d76da0cfbf0b2cf83b50b0895.png)

| 配置项 | 这是干嘛的 |
| --- | --- |
| 订单自动收货天数 | 用户不点「确认收货」，过 N 天系统自动帮他点 |
| 收货后自动完成天数 | 收货后过 N 天自动变成「已完成」状态 |
| 退货理由 | 预设一些退货理由，用户退货时快速选择 |

## 应用配置 📲

### 公众号配置

![image](images/5a17e69627d7c3b8f261b6af7c6796e4.png)

配置公众号登录方式：
- 微信授权登录（需先配置公众号信息）
- 手机号登录（短信验证 / 账号密码）

### 小程序配置

![image](images/2cef573410227204ac4aeaeb11a7090f.png)

小程序只支持微信授权登录，手机号验证有两种方式：

| 方式 | 说明 |
| --- | --- |
| 微信官方组件 | 需在微信小程序后台购买组件次数 |
| 短信验证 | 需注册一号通并购买短信条数 |

::: warning 注意
1.9 版本后，公众号和小程序的配置都在 yml 文件里完成。
:::

### 商品采集配置

![image](images/69d864814f0243939b9d7cb99f0088f5.png)

商品采集 = 一键复制别人家的商品信息到自己商城。懂的都懂 😏

**操作流程**：

**Step 1**：注册一号通并购买商品采集服务（或自己注册 99API）

**Step 2**：选择采集通道

![image](images/1f4992c6701f88835b7062d0b3a46c79.png)

**Step 3**：给商户分配采集次数

![image](images/40e831fa6e87a81d5c1009066c8c6bfe.png)

::: tip 小贴士
如果用自己的 99API 账号，就不用在一号通里买采集次数了。
:::

### 物流查询配置

![image](images/7969e8d2fd4fb2a0c70050c082199216.png)

接入物流追踪查询，让用户能实时看到包裹在哪儿。

操作方式：
1. 注册一号通账号
2. 购买物流查询次数
3. 在平台后台开启

::: warning 注意
物流查询只需平台配置，商户无需操作。查询费用由平台承担。
:::
