## 📝 实现的功能

### 核心功能

✅ **一键激活** - 访问任意文档 URL + `?dazongzi=666` 激活工具栏

✅ **平台预览** - 点击平台按钮即时预览该平台的格式化效果

✅ **样式转换** - 4 个平台各有专属的样式和排版规范

✅ **一键复制** - 自动复制格式化内容到系统剪贴板

✅ **智能降级** - 多层级复制方案确保兼容性（Clipboard API → execCommand → 手动复制）

✅ **完整覆盖** - 支持所有常见 HTML 元素（h1-h6、p、ul、ol、li、code、pre、img、blockquote、table、tr、td、th）

## 🚀 使用流程

```
第1步：启动开发服务器
└─ npm run dev
   服务运行在 http://localhost:5175/

第2步：打开文档 + 激活参数
└─ http://localhost:5175/01_初步了解/01_快速了解?dazongzi=666

第3步：看到工具栏
└─ 右上角出现"📢 一键复制到多平台"按钮栏

第4步：选择目标平台
└─ 点击：📱 微信 | ⚡ 掘金 | 📝 CSDN | 🎓 知乎

第5步：预览格式化效果
└─ 弹窗显示该平台的排版效果

第6步：一键复制
└─ 点击"📋 复制全文"，内容自动复制到剪贴板

第7步：粘贴到目标平台
└─ 打开各平台编辑器，Cmd+V 粘贴

第8步：发布
└─ 点击"发布"按钮完成！✅
```
